# JxTTS-releases
ผู้ช่วยไลฟ์สด TikTok และ YouTube ครบในโปรแกรมเดียว อ่านคอมเมนต์ออกเสียง ให้ AI ตอบแชท และแต่งหน้าจอไลฟ์ให้สวย บน Windows

🎙 JxTTS
เปลี่ยนคอมเมนต์ของผู้ชมให้เป็นเสียง เปลี่ยนไลฟ์เงียบๆ ให้มีชีวิตชีวา และช่วยให้คุณโฟกัสกับการไลฟ์ได้เต็มที่

คุณคงเคยเจอแบบนี้ มีคนพิมพ์ทักทายเข้ามา แต่คุณกำลังคุยเพลินจนไม่ทันเห็น พอเหลือบไปดูก็มีคอมเมนต์ไหลผ่านไปหลายสิบข้อความแล้ว ผู้ชมรู้สึกว่าถูกมองข้าม แล้วก็เลิกพิมพ์ไปในที่สุด

JxTTS ช่วยเติมช่องว่างนั้น ข้อความแชทจะถูกอ่านออกเสียงด้วยเสียงที่คุณเลือก ผู้ชมจะได้ยินคำพูดของตัวเองดังออกมาจากไลฟ์ ผู้ติดตามใหม่จะถูกทักทายด้วยชื่อทันทีที่เข้ามา และถ้าอยากให้มีคนคุยกับผู้ชมตลอดเวลา ก็ให้ AI ช่วยตอบแชทแทนได้เลย

บรรยากาศไลฟ์จะเปลี่ยนไปเลย ผู้ชมรู้สึกว่ามีคนฟังพวกเขาอยู่จริงๆ และกลับมาพิมพ์อีก

ไม่ต้องจ้างคนมาช่วยดูแชท ทุกอย่างทำงานอัตโนมัติอยู่เบื้องหลัง

เริ่มต้นใช้งาน
1. ติดตั้งโปรแกรมและเปิดขึ้นมา
2. ใส่ชื่อผู้ใช้ TikTok หรือช่อง YouTube ของคุณ แล้วเลือกเสียงที่ชอบ
3. กดเชื่อมต่อ แล้วไลฟ์ตามปกติ

🔊 มีอะไรในนั้นบ้าง

🗣 อ่านคอมเมนต์ออกเสียง (TTS)
อ่านแชทดังๆ ด้วยเสียงที่คุณเลือก กรองคำหยาบ อ่านอิโมจิ และแปลข้อความภาษาต่างประเทศให้อัตโนมัติ

📡 ไลฟ์หลายช่องพร้อมกัน
เชื่อมต่อ TikTok และ YouTube ได้หลายช่องในเวลาเดียวกัน ถ้าหลุดจะต่อให้ใหม่เอง

🤖 AI ตอบแชทอัตโนมัติ
สร้างโปรไฟล์ AI ได้หลายตัว ตั้งบุคลิก เสียง และคำสั่งเองได้ AI จำชื่อเล่นและนิสัยของผู้ชมแต่ละคนได้ และแบนคนกวนชั่วคราวให้เมื่อจำเป็น

🎁 แจ้งเตือนของขวัญและผู้ติดตาม
อ่านชื่อของขวัญเป็นภาษาไทย ตั้งเสียงและข้อความแยกรายชิ้นได้ และต้อนรับผู้ติดตามใหม่ด้วยชื่อทันที

🎨 ดีไซน์กล่องคอมเมนต์เอง
ปรับแต่งกล่องคอมเมนต์บนหน้าจอไลฟ์ได้ตามใจ ใส่อนิเมชั่น เปลี่ยนฟอนต์ และส่งออกหรือนำเข้าดีไซน์ได้ มีโหมดคอมเมนต์ลอยผ่านจอแบบ Bilibili ด้วย

🧑‍🎤 Avatar Live
รูปของคุณจะเด้งตามเสียงที่กำลังพูด

🎡 วงล้อสุ่มรางวัลและป็อปอัป
วงล้อสุ่มรางวัล วงล้อผู้เข้าร่วม และป็อปอัปที่ขึ้นเมื่อผู้ชมพิมพ์คำที่กำหนด

❤️ Heart Scene
ฉากบนจอเปลี่ยนตามจำนวนหัวใจที่ผู้ชมกด

🎬 หน้าเปิดไลฟ์และหน้าจบไลฟ์
ใส่วิดีโอ รูป เสียง และข้อความได้ รองรับ Chroma key และสั่งเล่นด้วยปุ่มลัด

⌨️ แสดงเมาส์และคีย์บอร์ดบนจอ
เหมาะกับสายเกมและสายสอน ปรับลายปุ่มและจัดวางได้เอง

💬 Subtitle จากเสียงพูด
พูดแล้วขึ้นคำบรรยายบนจอทันที ถอดเสียงในเครื่อง และแปลภาษาได้

🎵 วิดเจ็ตกำลังเล่นมีเดีย
โชว์ชื่อคลิปพร้อมหลอดเวลาจากเบราว์เซอร์ในตัว

🔗 ลิงก์ Overlay สำหรับ TikTok Studio
สร้างลิงก์สาธารณะผ่าน Cloudflare Tunnel ได้ในไม่กี่คลิก ใช้ได้ทั้งกับ OBS และ TikTok Studio

🧰 เครื่องมือเสริม
Auto Click, Rec Macro อัดเมาส์และคีย์บอร์ดแล้วเล่นซ้ำ, จับเวลาตามสีบนจอ, วาดบนจอ และเบราว์เซอร์ในตัวพร้อม AdBlock

💾 สำรองและย้ายการตั้งค่า
ส่งออกการตั้งค่าทั้งโปรแกรมเป็นไฟล์เดียว ย้ายเครื่องได้สบาย
